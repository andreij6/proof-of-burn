## Lobby (`Poker.tsx`) — PokerStars-style table list (PB-213)

Layout inspiration only; zero third-party branding (D17). Room name:
**"Caldera Hold'em"**.

```
┌ Caldera Hold'em — No-Limit · 25/50 · agents only · 0% RAKE, FOREVER ──┐
│ [Daily tournament banner: countdown / entrants / prize pool / podium] │
├───────┬──────────────┬─────────┬──────────┬─────────┬────────────────┤
│ TABLE │ STAKES       │ PLAYERS │ AVG POT  │ H/HR    │                │
│ Rush 1│ 25/50 NL     │ 7 / 9   │ 412      │ 51      │ [Watch]        │
│ Rush 2│ 25/50 NL     │ FULL    │ 1,205    │ 48      │ [Watch] (3 wl) │
│ …     │              │ 0 / 9   │ —        │ —       │ [Watch]        │
└───────┴──────────────┴─────────┴──────────┴─────────┴────────────────┘
[ Send my agent to a table ]        Bankroll: 12,400 chips (≈ 12.4 VP)
```

- 10 rows, monospace columns, `X / 9` in sprout when open, `FULL` chip in
  ember with waitlist count. Sort: players desc. Poll every 5 s.
- One primary CTA: **"Send my agent to a table"** → `poker_find_seat()`.
  No table/seat picker (D7). Disabled states: not signed in → "Sign in"; no
  agent → "Claim your agent in Profile" (links); effective VP < 0.5 →
  "Stake ICP to earn voting power first" (links to Earn).
- While `Searching/Waitlisted`: the CTA area is replaced by a pulsing
  **"Searching for a table…"** card (LiveDot + small waitlist position).
  When `Seated`, auto-navigate to the table view.
- Sub-line under the header repeats the no-loss promise: *"Chips are voting
  power — your staked ICP is never at risk. We take 0% rake — every chip in
  the pot goes to a player."* + MoreInfo dialog with doc-01 rules in plain
  words (R3/D26: the rake line is the headline, keep it everywhere the room
  is advertised).
- **Top strategies card** (R8): top-5 from `get_script_leaderboard` with a
  link into the marketplace.
- **Season strip** (R5/PB-222): current week's leaderboard (VP won · hands
  played) + the cosmetic prize on offer; past seasons' podiums collapsible.

## Table view (PB-214)

Canvas-free: pure DOM/CSS oval (matches app design system, dark felt
`--surface` tones).

- **9 seat pods** around an oval: avatar — the agent's **NFT profile
  picture** when set (D21), else a generated mini-SVG from the principal
  hash — plus the two-line identity `formatPrincipal(owner)` · `model badge`
  (D20: small mono chip, e.g. `claude-fable-5`), stack in chips, dealer
  button, blind chips, bet amounts in front of pods, fold = dimmed pod,
  all-in = burn-colored ring, acting seat = animated ring + countdown arc
  fed by `action_deadline`.
- **Board:** 5 card slots center, pot total above ("Pot: 1,250 · side 300").
  Card faces: clean SVG ranks/suits (original art).
- **My agent's hole cards**: rendered face-up at my agent's pod ONLY
  (`get_my_table_view`); every other pod shows card backs. Spectators with no
  seat see all backs (`get_table_public`).
- **No action controls ever** (agents-only). Footer states it: *"Your agent
  ⟨name⟩ is playing this seat — sit back."* + a **Recall agent** button
  (`poker_leave`, label "Stand up after this hand").
- **Action ticker** right rail: last ~20 events of the current hand
  ("seat 4 raises to 300…"), then the showdown result; previous-hand result
  pinned on top between hands.
- **Spectacle layer (D22 — this is a requirement):** the paced event stream
  (D18) gives the UI time to perform every beat:
  - cards **deal with a flip animation** clockwise from the small blind;
  - bets **slide chip stacks** from pod to the pot line; pot **slides** to
    the winner on award;
  - **winner glow** + hand-name banner ("Two pair, kings and queens") held
    through the 5 s inter-hand pause; busted seat does a fade-out;
  - showdown flips hole cards **one seat at a time** matching the server's
    reveal order;
  - **ambient SFX** on the existing WebAudio engine (new `tableSfx`): card
    slide, chip clack, all-in riffle, river thump, winner sting — same mute
    switch as arcade music;
  - a quiet **rail counter** ("12 watching") from a coarse spectator query
    counter.
  Because pacing is server-side, animations are driven by event timestamps —
  the UI never invents timing, so every spectator sees the same show.
- Polling: 2 s while a hand is live (cheap query), 5 s idle. (Push/heartbeat
  is out of scope for v1.)
- Mobile: pods shrink to chips+stack; board and ticker stack vertically.

## Profile → Agent Space (PB-215)

The existing Agent Space section gains a **Poker agent** card:

1. **Claim:** two options shown once —
   "Let Caldera play for me" (house mode, one click) vs "Register my own
   bot" (paste agent principal **+ declared model**, e.g. `claude-fable-5` —
   shown at every table, D20). Shows cooldown timer after a re-claim; model
   editable any time.
2. **Avatar (D21):** "Set profile picture from an NFT" — paste ICRC-7
   collection canister id + token id → backend verifies ownership → preview
   renders the cached image. Badge shows verification state; reverts to the
   generated avatar automatically if the NFT is sold. Clear button.
3. **Status:** Idle / Searching / Seated at Rush N / In tournament; bankroll
   in chips + effective VP; lifetime poker P&L (Σ delta), hands played.
4. **Tournament opt-in (D19):** today's tournament card with explicit
   "Register (1.0 VP)" / "Un-register" — mirrors the lobby banner; copy
   warns external-agent owners: *"Your agent must be online at 18:00 UTC —
   offline agents blind off."*
5. **Stop-loss (D23):** slider/input over effective VP with the 25% default
   marked; "off" requires an explicit extra confirm. `StopLossHit` state
   shows prominently with the two exits: **"Stake & get back in the game"**
   (restake nudge, R6 — deep-links to Earn with a suggested amount) or
   "Lower my floor" (eyes-open confirm).
6. **Play style:** picker (builtins + owned + licensed), active script badge,
   "New custom style — $5" → editor.
7. **Script editor:** form-based rule builder (street/position/hand-bucket/
   facing dropdowns + weighted-action rows) with a raw-JSON toggle; validate
   button mirrors canister checks; pay-with token row identical to the
   Arcade $1 modal.
8. **Marketplace tab:** browse listings (name, author, price, sales,
   lifetime VP stat), Buy modal (quote → pay → license appears in picker);
   "My listings" management (list/delist, price set in USD).

## Spectator acquisition (R7, PB-223)

- **Featured table card on the Dashboard hub**: the highest-pot live table,
  with seat count and a live pot ticker — one click to watch (works signed
  out; watching requires no agent).
- **Shareable hand replays**: every archived hand gets a deep link
  (`#/poker/hand/<table>/<no>`) that replays the paced event stream
  read-only (cards revealed per the archive — folded hole cards stay
  hidden forever). X-share button with auto copy: *"AA cracked by 7-2 on
  Caldera Hold'em — watch the replay"* (pattern: proposal sharing).
- **Rail counter** ("12 watching") from a coarse per-table spectator
  counter (incremented on watch, decayed by the sweep — approximate is fine).

## Copy rules

- Always "agent", never "bot", in user-facing copy.
- VP framing everywhere money-like numbers appear:
  `1,000 chips = 1.0 voting power`. Losses copy: *"Voting power moves between
  players. Your staked ICP never does."*
- Busted state (effective VP 0): banner across Poker + Voting pages —
  *"Your agent went broke — stake ICP to rebuild voting power."* with an
  Earn link. Stop-loss exits use softer copy (*"Your agent stopped at your
  floor"*) with the same one-click restake nudge (R6) — this button is the
  flywheel's conversion step, instrument it.

## Feature flag behavior

`poker` off ⇒ nav item hidden, all endpoints return `FEATURE_DISABLED`, the
page (if deep-linked) redirects to Dashboard — identical pattern to Lottery.
Admin Features panel picks the flag up automatically.
