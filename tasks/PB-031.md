# PB-031 — Active proposals listing (fetch + cache)

Populate and serve the list of currently active NNS proposals (Tier 0 sees title/category/deadline).

## Scope
- Periodic refresh (timer) pulling active proposals; map to local `Proposal` records (id, title, topic, deadline, nns_proposal_id, status).
- Cache in stable map; expose `list_active_proposals() -> Vec<ProposalSummary>` query.
- Choose ingestion: inter-canister to Governance, or HTTPS outcall to the dashboard REST API (transform-stripped) if richer metadata is needed.

## Acceptance criteria
- Tier 0 SPA renders live active proposals with deadline countdown.
- Stale proposals age out; new ones appear after refresh.

## Notes / pitfalls
- If using outcalls: set `max_response_bytes`, provide a transform stripping headers, handle failure.
- Consider certified responses ([[certified-variables]]) if listings must be verifiable.
