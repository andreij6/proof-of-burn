# PB-005 — Candid + TypeScript binding pipeline

Generate the `.did` interface and typed TS bindings for the frontend.

## Scope
- One-time: `cargo install candid-extractor`; generate `backend/backend.did` from the built wasm; commit it and reference it in the recipe `configuration.candid`.
- Frontend: `@icp-sdk/bindgen >= 0.3` + `@icp-sdk/core >= 5`; output to `src/frontend/src/bindings/` via the Vite plugin.

## Acceptance criteria
- `createActor` from generated bindings calls a backend query successfully from the SPA.
- Regenerating bindings after a backend interface change updates types.

## Notes / pitfalls
- New bindgen API: `createActor(canisterId, { agentOptions: { host, rootKey } })`. Passing `{ agent }` silently yields an anonymous identity.
- There is no `dfx generate` equivalent.
