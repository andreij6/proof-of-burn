# PB-013 — Owner/admin access control

Implement guard-based authorization for all privileged methods.

## Scope
- `require_authenticated` (reject `Principal::anonymous()`), `require_owner`, `require_admin` returning `Result<(),String>`.
- Apply via `#[update(guard = "require_admin")]` on config/threshold/admin-management methods.
- `add_admin` / `remove_admin` (owner-only) — **include revocation**.

## Acceptance criteria
- Anonymous and non-admin callers are rejected on every privileged method.
- Admin add/remove works and is covered by tests.

## Notes / pitfalls
- `inspect_message` is a cycle optimization, NOT a security boundary — duplicate checks in each method/guard.
- Prefer the `guard` attribute over in-body checks (can't forget it).
