# PB-082 — Storage quotas & input validation

Prevent unbounded user-controlled storage and malformed input.

## Scope
- Per-principal limits on commitments/records; validate sizes/ranges on all inputs (amounts, ids, strings).
- Reject oversized payloads early.

## Acceptance criteria
- Attempted unbounded writes are capped; invalid inputs rejected with typed errors.

## Notes / pitfalls
- An attacker filling stable memory can brick the canister — enforce quotas.
