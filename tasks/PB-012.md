# PB-012 — Canister init / post_upgrade & config bootstrap

Initialize config (primary neuron ID, admins, default threshold, AI price) and restore transient state after upgrade.

## Scope
- `#[init]` takes init args (owner principal, primary neuron id, default threshold, ai price); persist to `Config` cell.
- `#[post_upgrade]` re-establishes timers/transient caches (stable data auto-restores).
- Config getters (query) + admin setters (guarded — see [[PB-013]]).

## Acceptance criteria
- Both `#[init]` and `#[post_upgrade]` defined; deploy and upgrade succeed.
- Querying config returns the values passed at init.

## Notes / pitfalls
- Missing `#[post_upgrade]` can silently reset behavior.
- Capture owner from init args; do not trust the anonymous principal as a default owner on mainnet.
