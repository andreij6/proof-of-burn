# PB-061 — Event triggers for social posts

Wire the two spec events to X posts.

## Scope
- Triggers: (1) proposal reaches burn threshold ([[PB-041]]); (2) a vote is cast and ICP is burned ([[PB-042]]/[[PB-033]]).
- Debounce/dedupe so each event posts once.

## Acceptance criteria
- Each of the two events fires exactly one post with correct content.
- Re-processing the same event does not double-post.

## Notes / pitfalls
- Tie dedupe to a persisted event id, not in-memory state (survives upgrades).
