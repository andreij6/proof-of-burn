# PB-208 — Play-style DSL: schema, validator, bounded interpreter, presets

Plan: `plans/poker/` (see README.md for locked decisions D1–D17).

## Scope (plans/poker/04)
- JSON schema v1 (rules/when/do, hand buckets, weighted actions, params),
  8 KB / 200-rule caps; validator with path-precise errors.
- Interpreter: bucket computation (preflop groups + postflop strength/draw),
  first-match rule, weighted draw from hand RNG stream, fallback ladder,
  clamp-to-legal.
- Builtin presets: Standard TAG (default), Rock, Loose-Passive, Maniac.

## Acceptance
- Validator corpus (valid + each failure class); golden-decision tests per
  preset; clamping fuzz (never an illegal action); determinism replay.
