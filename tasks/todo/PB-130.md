# PB-130 — Config: admin-configurable pool initiation fee

Add an admin-configurable initiation fee for joining the neuron pool. Default
125 ICP. Plan §1 ("Config additions"), decision #3.

## Backend
- Add `pool_initiation_fee_e8s: u64` to `Config` with `#[serde(default)]` (CBOR
  field-map upgrade-safe pattern). Default `12_500_000_000` (125 ICP) — applied
  in `init`/default and via serde default on upgrade for existing state.
- Add admin endpoint `admin_set_pool_fee(new_fee_e8s: u64) -> Result` guarded by
  `require_admin`. Reject `0`.
- Surface the field in `get_config`.

## Acceptance Criteria
- [ ] `get_config().pool_initiation_fee_e8s` returns 125 ICP on a fresh deploy.
- [ ] Upgrading a canister that predates this field yields the 125 ICP default
      (no trap, state preserved).
- [ ] `admin_set_pool_fee` changes the value; a non-admin caller is rejected;
      `0` is rejected.
- [ ] Unit test asserts the default constant and the admin setter guard.
