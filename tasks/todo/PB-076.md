# PB-076 — Personal dashboard strip (Tier 3)

Compact summary bar for active participants.

## Scope
- Stats: total ICP committed, proposals participated in, ICP burned to date; per-proposal commitment status (pending/met/burned/returned).

## Design source
Recreate `DashStrip` (`design-system/project/pob-parts.jsx`): a `--burn`-bordered strip on `--burn-950` with three stats (Committed / Burned to date / Proposals joined), each an `Icon` + `useCountUp` mono ticker + `Eyebrow` label. Tier 3 only. Per-proposal status reuses the `mineBadge` `Chip`s from `ProposalRow`.

## Acceptance criteria
- Appears only at Tier 3; figures match backend aggregates.

## Notes / pitfalls
