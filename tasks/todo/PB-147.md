# PB-147 — Manual verification + local deploy

End-to-end manual run on the local network before any mainnet consideration.
Plan §8 (Manual). Do **not** deploy to mainnet as part of this task.

## Steps
1. Build + deploy backend & frontend to local (`--identity anonymous`).
2. Sidebar → Follow → wizard. Step 2 Verify (local skips NNS) → neuron shows as
   **Draft**.
3. Close wizard; confirm Draft persists and "Resume setup" returns to the pay
   step.
4. Fund `get_registration_address` with `fee + 0.0003 ICP`; Finalize → confirm
   50/25/25 fee split (treasury + backend cycles + frontend cycles); neuron →
   **Active**; leader card shows "+ X Pooled Voting Power".
5. Settle a proposal with a non-empty pool → 25% pool share paid from treasury to
   the registered principal; treasury nets 25%. Empty pool → treasury keeps 50%.
6. Exercise `cancel_pool_draft` + `refund_registration` and
   `unregister_leader_neuron` (→ Inactive).
7. Resize to mobile width: sidebar collapses to a toggle and opens full-screen.
