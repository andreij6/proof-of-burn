# PB-220 — Early Adopters VP: 6x multiplier into staking weight (platform-wide)

Plan: `plans/poker/` (decisions D25–D26).

## Goal (D25 — applies platform-wide, independent of poker shipping)
EA stakers currently get yield shares but NO voting power. Their permanent
2-year lock should earn VP like the staking tiers do, at a premium.

## Scope
- `ea_weight_e8s(user) = ea_staked_e8s / 10 * 6` — above the 2y tier's 4x,
  reflecting the permanent lock.
- Fold into `staking_total_weight_e8s` (the same base poker's effective VP
  uses, PB-200); `get_my_stake` + `get_early_adopters_info` expose it.
- Lossless votes and balance-of-power reads pick it up automatically via
  the shared helper; lottery tickets explicitly NOT granted by EA stake
  (tickets stay tier-stake-based — regression-tested).
- UI: EA page shows "Voting power earned: X (6x multiplier)"; staking page
  weight explainer mentions the EA tier; doc updates (GROWTH_TARGETS
  economics note: EA now also a VP source).

## Acceptance
- Unit tests: weight math, vote weight includes EA, tickets unchanged,
  poker effective-VP base includes EA (with PB-200 in place).
- Existing EA member sees nonzero VP after upgrade with no action needed.
