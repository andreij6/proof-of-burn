# PB-135 — `finalize_pool_registration` (final paid step + fee-split saga)

Phase 2: the final, paid step. Re-verify, consume the funded escrow, run the
50/25/25 fee-split saga, and flip the neuron to **Active**. Plan §2 Phase 2.

## Backend
- `finalize_pool_registration(neuron_id: u64) -> Result` (update):
  1. Assert caller owns a `Draft` (or `Inactive`) `PoolNeuron` for `neuron_id`,
     else `NO_DRAFT`.
  2. **Re-verify** hotkey + follow via `get_full_neuron` (skipped when
     `is_local`) — guards against the hotkey being pulled after drafting.
  3. Assert registration escrow balance ≥ `pool_initiation_fee_e8s + 30_000`,
     else `INSUFFICIENT_DEPOSIT`.
  4. Fee-split **saga** (idempotent, guarded by the three `*_block` fields, same
     shape as `settle_burn_split`):
     - 50% → treasury subaccount
     - 25% → backend cycles (CMC transfer + `notify_top_up`, target = self)
     - 25% → frontend cycles (CMC, target = `frontend_canister_id()`)
  5. Set `status = Active`, `activated_at = now`; `recompute_pool_info()`;
     audit-log `pool_register`.
- On step-2 failure, move no funds (deposit stays in escrow; neuron stays Draft).

## Acceptance Criteria
- [ ] Finalizing a funded Draft splits the fee 50% treasury / 25% backend cycles /
      25% frontend cycles and sets the neuron `Active` with `activated_at` set.
- [ ] No Draft → `NO_DRAFT`; underfunded escrow → `INSUFFICIENT_DEPOSIT`;
      re-verify failure → error and **no funds moved**.
- [ ] Saga idempotency: a retry after a partial failure does not double-spend
      (block-index guarded) — integration test mirrors the settlement saga test.
- [ ] After finalize, the neuron is counted by `recompute_pool_info()` and the
      cycle top-ups reach the CMC (AlreadyNotified treated as success).
- [ ] On `is_local`, re-verification is skipped; the split still executes.
