# PB-164 — Frontend: fixed-point physics engine (TypeScript) + golden tests

Implement the PB-160 spec as a pure, dependency-free module. Plan §3.

## Frontend
- `src/frontend/src/golf/physics.ts`: pure functions over integer state —
  `simulateShot(course, hole, ballPos, shot) -> { steps, finalPos, events,
  strokesDelta }` plus a step-wise iterator the renderer consumes for
  animation. All arithmetic in fixed point (1/1024 px) using `bigint`-free
  `number` integer ops (values bounded « 2^53; document the bound).
- Shot quantization helper: pointer drag vector → `(angle_mrad, power)`
  with the shared 1024-entry sine LUT (generated once, checked in).
- Hazard + cup + wall reflection semantics exactly per spec; per-shot
  3600-step cap; 12-stroke hole cap surfaced as a `Pickup` event.
- No rendering, no React, no Date/Math.random in this module.

## Tests (vitest)
- All PB-160 golden vectors pass byte-exact.
- Determinism: same inputs replayed 100× yield identical outputs.
- Property checks: ball never escapes course bounds; energy never
  increases after a wall bounce.

## Acceptance Criteria
- [ ] `physics.ts` has zero imports (pure module).
- [ ] Golden suite green; vectors imported from `golf/golden.json` verbatim.
- [ ] Engine simulates a full 9-hole round in < 50 ms on a laptop
      (perf note in test output, not a hard assert).
