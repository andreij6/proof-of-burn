# PB-043 — Refund on expiry without threshold

If a proposal's deadline passes without meeting threshold, return all committed ICP — **no burn**.

## Scope
- Deadline timer/sweep: for unmet proposals, `icrc1_transfer` escrow → original committers (minus ledger fee handling per product decision).
- Mark commitments `Returned`; write audit log entries.

## Acceptance criteria
- Expired-unmet proposal returns funds to each committer; status `Returned`; nothing burned.
- Sweep is idempotent and resumable if interrupted mid-batch.

## Notes / pitfalls
- Decide who absorbs the transfer fee on refund (product decision — surface in UI per spec "no burn, funds returned").
- Guard against double-refund using the audit log / status checks across `await`.
