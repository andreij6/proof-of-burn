# PB-161 — Backend: golf config, feature flag, entry-fee escrow + 50/25/25 split saga

Pay-to-play plumbing. Plan §1–2.

## Backend
- Add `mini_golf` to `KNOWN_FEATURE_FLAGS`, `feature_default` → **false**
  (ships dark; admin enables via existing flag panel).
- `Config` additions (`#[serde(default)]`, upgrade-safe):
  `golf_entry_fee_e8s: Option<u64>` (None → 25_000_000) and
  `golf_course_version: Option<[u8; 32]>` (+ holes_count, par_total cells as
  needed). Admin setters `admin_set_golf_fee` (reject 0) and
  `admin_set_golf_course(hash, holes, par)`.
- `GolfRound` stable map at MemoryId 18 + `NEXT_ROUND_ID` cell at 19
  (verify 0–17 in use; document).
- `get_golf_deposit_address()` query — caller subaccount, domain
  `proof_of_burn_golf_v1`.
- `start_golf_round() -> Result<u64>`: auth + flag + CallerGuard; reject a
  second `Paid` round inside the 2 h TTL (lazily expire stale); escrow
  balance ≥ fee + 3×10_000; journal the round THEN run the 50/25/25
  treasury/backend-CMC/frontend-CMC split with per-step block guards and
  CMC notify (reuse `call_cmc_topup_transfer` + `notify_cmc_topup`).
- Sweep `retry_failed_golf_fees()` wired into `setup_timers` +
  `admin_trigger_sweep`.
- Audit events: `golf_round_start`. Candid + bindings regenerated.

## Acceptance Criteria
- [ ] Flag off ⇒ `start_golf_round` returns `FEATURE_DISABLED`.
- [ ] Underfunded escrow ⇒ `INSUFFICIENT_DEPOSIT`, no round stored.
- [ ] Mid-saga ledger failure leaves a journaled round the sweep completes
      (unit test with mocked transfer Err → Ok).
- [ ] Double-start inside TTL rejected; allowed after expiry.
- [ ] Treasury receives exactly 50% of the fee (host test, split math).
