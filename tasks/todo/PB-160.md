# PB-160 — Deterministic physics spec + golden vectors

Author the shared fixed-point physics specification both the TypeScript
client and the (Phase-2) Rust validator implement. Plan §3.

## Deliverables
- `docs/GOLF_PHYSICS.md`: fixed-point units (1/1024 px), 120 Hz timestep,
  ball radius, friction constants (green 1023/1024, sand 1015/1024),
  restitution 31/32, stop threshold, cup capture rule (distance + speed),
  water/sand semantics, wall set (axis-aligned + 45° only), shot encoding
  `(angle_mrad: i32, power: 0..=1000)`, 1024-entry sine LUT definition,
  30 s/3600-step per-shot cap, 12-stroke hole cap.
- `src/frontend/src/golf/golden.json`: ≥ 25 canonical vectors
  (course-hole + ordered shots → final ball position, strokes, events such
  as water reset / cup capture). Hand-computed or generated from the
  reference implementation once and frozen.

## Acceptance Criteria
- [ ] Spec contains no floating-point operations in the simulation path.
- [ ] Every constant in the spec has a rationale comment.
- [ ] Golden vectors cover: straight putt, bank shot, 45° wall, sand entry,
      water reset (+1 stroke), lip-out (too fast over cup), capture,
      max-step forced stop, stroke-cap pickup.
- [ ] Vectors file is consumed by BOTH vitest (PB-164) and cargo (PB-169)
      without transformation.
