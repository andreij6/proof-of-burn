# PB-140 — Candid (`backend.did`) updates for pooling

Expose the new types and endpoints in the Candid interface so the frontend
bindings generate. Plan §6 (backend.did).

- Add `PoolStatus` variant, `PoolNeuron` record, and `PoolInfo` record.
- Add `pool_initiation_fee_e8s : nat64` to `Config`.
- Add `pool_distributed : bool` to `Proposal`.
- Add service methods: `get_registration_address`, `create_pool_draft`,

  `admin_set_pool_fee`.
