# PB-219 — Stop-loss: per-agent VP floor, default 25%, settlement check + UI

Plan: `plans/poker/` (D23; 01_economics_vp.md §Stop-loss, 06_ui.md, 08_flywheel.md).

## Scope

- `stop_loss_e8s: u64` on PokerAgent (0 = off); default at claim = 25% of
  the owner's staking weight at that moment (absolute value stored).
- `set_stop_loss(e8s)` — owner-only; applies from the next hand.
- Enforcement (exactly two places):
  1. post-settlement: `effective_weight_e8s <= floor` => auto stand-up,
     state `StopLossHit`;
  2. sit-down / tournament registration: rejected (`STOP_LOSS_FLOOR`) when
     the minimum buy-in could not be lost without breaching the floor.
- Never rewrites a hand: an all-in loss settles in full; the floor only
  triggers the exit.
- UI (with PB-215): slider with 25% default marked, "off" needs an explicit
  confirm; `StopLossHit` state renders the **restake nudge** (R6 — "Stake &
  get back in the game" deep link to Earn) and "Lower my floor"; instrument
  the nudge click-through (the epic's primary KPI, D24).

## Acceptance

- Unit tests: default computation at claim, post-hand trigger (boundary ==
  floor), sit-down/registration rejections, off-mode, edit-between-hands
  semantics, all-in loss still settles fully.
- PocketIC: agent hits floor mid-session => stood up, cannot re-seat, lowers
  floor => can re-seat.
- vitest: slider states, StopLossHit banner + nudge link.
