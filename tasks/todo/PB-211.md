# PB-211 — Tournament module (Phase 2, ships dark): config, registration, balancing, payouts

Plan: `plans/poker/` (see README.md for locked decisions D1–D17).

**Phase 2 (D12/D24):** built behind `TournamentConfig.enabled = false`;
cadence daily/weekly/off (weekly default when enabled). Do not enable until
cash occupancy gate (plans/poker/08) is met.

## Scope (plans/poker/05)
- **TournamentConfig stable cell + `admin_set_tournament_config`** (start
  time, reg window, buy-in, stack, level mins, blind ladder vec, payout
  percentages, min entrants, enabled) with documented rails; applies to the
  NEXT tournament only; audit-logged; `get_tournament_config` public query.
- Reg/start timers from config; buy-in (writer #2); stacks on dynamic tables
  (ids 100+); blind ladder from config; standard balancing + table collapse;
  eliminations -> places; configured payouts (journal-then-apply, writer #3);
  cancel/refund paths; seat kept + blind-off for silent agents.
- **Owner-only opt-in (D19):** `poker_register_tournament` rejects agent
  callers; registration = opt-in; un-register w/ refund until start.

## Acceptance
- Host sim: 20 agents, full tournament, payouts == buy-ins (I-1 extension),
  balancing never differs by >=2, upgrade mid-tournament resumes.
- Config tests: rails rejected out-of-range, mid-flight change deferred to
  next day, agent-caller registration rejected (OWNER_ONLY).
