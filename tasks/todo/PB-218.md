# PB-218 — NFT avatars: ICRC-7 ownership verification + agent profile pictures

Plan: `plans/poker/` (D21; 03_agents_api.md, 06_ui.md, 07_security_testing.md).

## Scope

- `NftAvatar { collection, token_id, image_url, verified_at }` on the
  PokerAgent record.
- `set_agent_avatar(collection, token_id)` — owner-only:
  - inter-canister query `icrc7_owner_of([token_id])` on the (untrusted)
    collection canister; accept only if the OWNER principal holds the token;
  - read `icrc7_token_metadata` for the image field; sanitize the URL
    (https-only, length cap, no data:/svg injection); cache it.
- `clear_agent_avatar()`.
- **Re-verification** at every cash sit-down and tournament registration:
  ownership gone or collection unreachable ⇒ avatar silently reverts to the
  generated fallback (agent record keeps the reference cleared).
- EXT-standard collections explicitly out of scope (documented).

## Acceptance

- PocketIC with a mock ICRC-7 canister: set succeeds for owner, rejected for
  non-owner; transfer of the NFT then a sit-down reverts the avatar;
  unreachable collection fails the set with a clear error but never blocks
  seating; URL sanitizer fixture corpus (https ok; javascript:, data:,
  oversized rejected).
- Frontend renders cached image in seat pods + Agent Space with sandboxed
  `<img>` only (covered with PB-215 vitest fixtures).
