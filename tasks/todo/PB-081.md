# PB-081 — Cycles management, freezing threshold & backup controller

Protect the high-value backend canister from freezing and key loss.

## Scope
- Raise `freezing_threshold` (e.g., 90 days) on backend; set up cycles monitoring + top-up.
- Add a backup controller (or governance/SNS principal) — no single-key control.

## Acceptance criteria
- Backend has ≥2 controllers and an elevated freezing threshold on mainnet.
- Cycle balance alerting in place.

## Notes / pitfalls
- Losing the sole controller key = permanently unupgradeable canister; zero cycles = uninstall (state lost).
