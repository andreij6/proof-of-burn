# PB-020 — Internet Identity sign-in (frontend)

Add II login/logout and an authenticated agent. (Default standard; Plug/OISY deferred per spec open question.)

## Scope
- `@icp-sdk/auth/client` `AuthClient`; `identityProvider` = `http://id.ai.localhost:8000` locally / `https://id.ai` on mainnet.
- `maxTimeToLive` 8h default; build authenticated actor with `rootKey` from `safeGetCanisterEnv()` (`ic_env` cookie).
- Header shows connected principal; `onSuccess`/`onError` handled.

## Acceptance criteria
- Login yields a non-anonymous principal; logout clears it.
- Authenticated query to backend returns the caller's principal.

## Notes / pitfalls
- Provider URL points to the II **frontend** canister, not backend.
- Getting `2vxsx-fae` means auth silently failed (wrong URL / missing onSuccess).
- Never call `fetchRootKey()` — use the `ic_env` cookie root key.
