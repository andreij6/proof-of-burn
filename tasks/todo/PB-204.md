# PB-204 — Cash-table lifecycle: 10 tables, hand loop, timers, seat loss

Plan: `plans/poker/` (see README.md for locked decisions D1–D17).

## Scope (plans/poker/02 driver)
- 10 static tables (25/50); hand loop: raw_rand -> commit -> deal -> action
  deadlines via `ic_cdk_timers`; action-driven progression.
- **Pacing engine (D18):** buffered action reveal 2-4 s (seeded), 1.5 s
  street pause, staggered showdown reveals, 5 s inter-hand => every hand
  plays out >= ~10 s, watchable like a broadcast. `admin_set_poker_pacing`
  with rails; pacing constants in one struct.
- Timeout policy: check/fold; 2-in-hand or 3-hands-running => stand up.
- Per-hand settlement -> POKER_VP_DELTA; stack clamp to effective VP at hand
  start; busted => stand up; min 500 chips to be dealt in.
- post_upgrade timer re-arm; idle tables schedule nothing.

## Acceptance
- Unit tests with mocked time/rand: full hands settle zero-sum; timeout
  unseats; clamp rule; upgrade-resume simulated via state serialize.
