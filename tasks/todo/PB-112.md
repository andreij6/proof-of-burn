# PB-112 — Real PocketIC integration tests for the burn saga

**The existing automated tests do not exercise the canister.** [[PB-090]]'s tests are pure-Rust unit tests (Storable roundtrips, constant checks, helper logic) and [[PB-092]] is a bash script requiring manual verification. There is **zero automated coverage** of `commit → settle → burn/refund`, access control, or eligibility at the canister boundary — exactly the high-risk surface that moves real ICP.

## Scope
Add a `tests/` crate using **PocketIC** with a local ICRC-1/2 ledger (and a stub CMC + stub NNS Governance) covering:

- **Access control:** anonymous rejected on every update; non-admin rejected on admin methods; admin add/remove + last-admin protection.
- **Eligibility:** `register_neuron` controller mismatch rejected; follow verification true/false; tier resolution 0–3.
- **Commit:** below-minimum, over-global-cap, over-stake-cap, already-committed, too-many-commitments, insufficient-deposit, commitment-closed (post-cutoff), commit allowed on `"met"` proposal (oversubscription).
- **Settlement — threshold met:** escrow → CMC burn → `notify_top_up` → `Burned`, vote cast, aggregates + audit log updated.
- **Settlement — threshold missed:** `abstained` → refund → `Returned`, net amount correct (minus ledger fee).
- **Saga failure/retry:** stub ledger/CMC that fails on first attempt; assert retry reaches a terminal state with **no double transfer** (validates [[PB-111]]).
- **NNS reject on mainnet ledger id:** assert no eligibility granted and no burn (validates [[PB-110]]).
- **Every `TransferError` branch** (BadFee, InsufficientFunds, TooOld, …) surfaces a typed error, not a panic.

## Acceptance criteria
- `cargo test` (or `pocket-ic` runner) runs the suite green in CI.
- Both burn and refund lifecycles pass end-to-end against the mock ledger.
- Ledger balances and commitment statuses match expectations after each scenario.

## Notes / pitfalls
- Pin the PocketIC server version compatible with the project's replica.
- Download the ICRC ledger + CMC test wasms once and cache them (network 504s have bitten local deploys before — vendor the wasm).
- Burns must hit the CMC with the correct fee; refunds must return `amount − 10_000`.
