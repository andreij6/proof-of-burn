# PB-180 — Backend: price config, feature flag, AiReview data model, deposit/refund endpoints

Foundations for the paid reviewer. Plan §1–2, decisions #2/#6.

## Backend
- `ai_reviewer` added to `KNOWN_FEATURE_FLAGS`, `feature_default` →
  **false** (ships dark; an admin enables it deliberately via the existing
  flag panel, and the same flag is the kill switch). All reviewer update
  methods and the UI button are gated on it.
- Fresh-deploy default `ai_price_e8s = 300_000_000` (3 ICP) in `init` +
  the thread-local default Config. New
  `admin_set_ai_price(e8s) -> Result` guarded by `require_admin`;
  reject `0` and values > 100_000_000_000 (1000 ICP fat-finger guard).
- Types per plan: `AiReviewStatus`, `AiReview` (with the three 50/25/25
  block guards + `generation`, `prompt_version`, `model`, vote counters).
  `impl_storable!` both.
- Stable maps: `AI_REVIEWS` at MemoryId **24**, `AI_REVIEW_VOTES`
  (`(u64, u32, Principal) -> u8`) at MemoryId **25**. Confirm 18–23 remain
  reserved for Epic G (comment at the declaration site).
- `get_ai_review_deposit_address(nns_proposal_id)` query — caller-bound
  subaccount, domain `proof_of_burn_ai_review_v1`.
- `refund_ai_deposit(nns_proposal_id) -> Result` — sweeps any unspent
  escrow balance back to the caller (mirror of `refund_registration`).
- `get_ai_review(nns_proposal_id) -> opt AiReviewView` query: `Ready` only;
  view includes content, sponsor, model, generation, vote counts, and the
  caller's own vote (if any).
- Candid + bindings regenerated.

## Acceptance Criteria
- [ ] `get_config().ai_price_e8s == 300_000_000` on fresh local deploy.
- [ ] `admin_set_ai_price` guard + bounds covered by host tests.
- [ ] Deposit subaccount differs from idea/project/golf domains for the
      same (caller, id) (collision test).
- [ ] `refund_ai_deposit` returns escrow minus one ledger fee; empty
      escrow ⇒ `NOTHING_TO_REFUND`.
- [ ] Storable roundtrip tests for `AiReview`.
