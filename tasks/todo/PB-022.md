# PB-022 — Neuron-follow verification (Tier 2 gate)

Verify on-chain that the signed-in user is following the primary neuron in the NNS.

## Scope
- Resolve the verification model (DECISION): user proves control of a neuron (principal/hotkey is a controller) and we read that neuron's `followees` for the relevant topic(s) to confirm the primary neuron is a followee.
- Inter-canister call to NNS Governance (`get_full_neuron` / `list_neurons`) — see [[PB-030]].
- Cache follow status per principal with a TTL; expose `is_following(caller) -> bool`.

## Acceptance criteria
- A user following the primary neuron resolves to Tier 2; a non-follower does not.
- Verification re-checks after TTL and on demand.

## Notes / pitfalls
- Use bounded-wait inter-canister calls so a slow Governance response can't block upgrades.
- Don't read state before an `await` and assume it's unchanged after (TOCTOU).
- **Blocked until the verification model is locked** (see README decisions).
