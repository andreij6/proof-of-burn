# PB-133 — Registration escrow address + refund

Add the per-user registration escrow used to fund the initiation fee, plus a
reclaim path. Plan §2 ("Phase 2" escrow + `refund_registration`).

## Backend
- Add a `REGISTRATION_SEED` and reuse `derive_subaccount(caller, REGISTRATION_SEED)`
  to produce a per-principal registration subaccount, **distinct** from the
  commit escrow subaccount.
- `get_registration_address() -> LedgerAccount` (query): returns
  `{ owner: ic_cdk::id(), subaccount: Some(registration_subaccount) }`.
- `refund_registration() -> Result` (update): transfers the caller's
  registration-escrow balance back to the caller's wallet (single ICRC transfer,
  minus 0.0001 fee). Returns `NOTHING_TO_REFUND` if balance is 0 (idempotent).

## Acceptance Criteria
- [ ] `get_registration_address` returns a subaccount that differs from
      `get_deposit_address`/commit escrow for the same caller (unit test on the
      derivation).
- [ ] Funding the registration address then calling `refund_registration` returns
      the funds minus one ledger fee (integration test).
- [ ] `refund_registration` on an empty escrow returns `NOTHING_TO_REFUND` and
      moves nothing (idempotent — second call is a no-op).
- [ ] Anonymous caller is rejected.
