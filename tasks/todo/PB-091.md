# PB-091 — Upgrade persistence tests

Prove all state survives `icp deploy` upgrades.

## Scope
- Seed proposals/commitments/votes/reviews → upgrade → assert counts and values unchanged; assert transient caches reset.

## Acceptance criteria
- Post-upgrade data identical to pre-upgrade; transient state reset as designed.

## Notes / pitfalls
- If counts drop to 0 after upgrade, data isn't in stable memory — fix storage declarations.
