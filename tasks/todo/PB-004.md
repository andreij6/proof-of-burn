# PB-004 — Backend Cargo crate & dependency pinning

Configure the Rust canister crate with the exact dependency set used across the backend.

## Scope
- `Cargo.toml`: `crate-type = ["cdylib"]`, `edition = "2021"`.
- Deps: `ic-cdk = "0.19"`, `candid = "0.10"`, `ic-stable-structures = "0.7"`, `icrc-ledger-types = "0.1"`, `serde = { version = "1", features = ["derive"] }`, `ciborium = "0.2"`, `serde_json = "1"`.
- `ic_cdk::export_candid!();` at the end of `lib.rs`.

## Acceptance criteria
- `icp build backend` compiles to wasm32 with no warnings on the dependency wiring.
- Candid extraction works (see [[PB-005]]).

## Notes / pitfalls
- Keep `Cargo.lock` committed; the rust recipe supports `locked`.
