# PB-092 — End-to-end burn flow test

Full lifecycle on the local network with the local ledger.

## Scope
- Scenario A (threshold met): approve → commit (multiple users) → threshold → burn → vote → records.
- Scenario B (expiry unmet): commit → deadline → refund, nothing burned.

## Acceptance criteria
- Both scenarios pass end-to-end; ledger balances and statuses match expectations.

## Notes / pitfalls
- Verify burns hit the minting account with fee 0; verify refunds return correct net amounts.
