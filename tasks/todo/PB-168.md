# PB-168 — Frontend: leaderboard UI — weekly/monthly tabs, countdown, my rank

The competitive surface that makes pay-to-play sticky. Plan §4.

## Frontend
- Leaderboard tab inside the Burn Putt page: **Weekly / Monthly** toggle,
  period navigation (current and past periods via `period_id` arg),
  countdown chip to the next period reset (from `get_golf_info()` reset
  timestamps), course-version tag when a row predates the current course.
- Table rows: rank, principal (formatPrincipal), total strokes,
  par-relative (e.g. −3), submitted date. Caller's row highlighted in burn
  accent and pinned below the table when ranked > 100.
- Empty states ("no rounds this week yet — be first") and loading states
  per house patterns; mobile: table degrades to stacked cards.
- "My best" chip on the play screen sourced from the same query.

## Acceptance Criteria
- [ ] Weekly and monthly boards show independent data; period navigation
      retrieves a past period correctly.
- [ ] Countdown matches the backend's reset timestamp (UTC), not local
      heuristics.
- [ ] Caller-outside-top-100 sees their own rank row.
- [ ] Vitest: rank rendering, par-relative formatting, countdown math.
