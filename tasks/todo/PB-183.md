# PB-183 — Frontend: replace the AIPanel mock — button, PayDialog, ReviewDialog, votes

The user-facing loop: button on the proposal → pay → read → vote.
Plan §4.

## Frontend (App.tsx + new components)
- Remove the mock `aiReviews` record and the `aiMode` tweak-panel coupling
  for real data (keep the tweak panel switch as a pure visibility toggle).
- Lazy fetch: `get_ai_review(nns_proposal_id)` when a proposal's panel/
  button is first rendered (cache results in component state by id).
- Button states on each proposal card (Open + Committed tabs):
  1. **No review:** `✨ AI review · {fmtICP(config.ai_price_e8s)} ICP` —
     opens **PayDialog**: price line, house two-step escrow flow
     (`get_ai_review_deposit_address` → `icrc1_transfer(price + 4×fee)` →
     `request_ai_review`), progress state "Consulting Llama 4 Scout — this
     can take up to a minute…", disclosure footer (model + DFINITY AI
     workers; cached publicly; community can vote it out).
  2. **Cached:** `✨ AI review` chip with net-vote count — opens
     **ReviewDialog**: pre-wrap content, meta line (sponsored by
     {formatPrincipal}, model, date), 👍/👎 with live counts; caller's
     prior vote highlighted + further voting disabled.
- Vote → `vote_ai_review(id, generation, up)`; a `null` response means
  deleted: toast "The community voted this review out", close dialog,
  revert button to pay state, clear local cache entry.
- Race handling: `request_ai_review` returning a cached review the user
  didn't pay for shows it + a note that their deposit is reclaimable
  (button calls `refund_ai_deposit`).
- Anonymous: reviews readable; pay/vote CTAs route to sign-in.
- All styling from design-system tokens; modals follow the house overlay
  pattern.

## Acceptance Criteria
- [ ] Full local loop works in the browser: pay (mock review appears) →
      visible to a second identity free → downvote ×2 deletes → button
      returns to pay state.
- [ ] Price always rendered from config, never hardcoded.
- [ ] In-flight dialog survives the long update call without UI lockup.
- [ ] Vitest: button state machine, vote flows incl. deletion toast.
