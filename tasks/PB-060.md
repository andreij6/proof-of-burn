# PB-060 — X/Twitter posting via HTTPS outcall

Post to X from the canister.

## Scope
- HTTPS outcall (POST) to the X API with OAuth2 bearer auth; transform strips headers; idempotency key per event.
- Compose post templates for the two event types ([[PB-061]]).

## Acceptance criteria
- A test event produces a live post (or a dry-run log in non-prod).
- Provider/auth errors are handled without trapping.

## Notes / pitfalls
- X bearer token is a secret — do NOT store in canister state; use vetKD/proxy. **Resolve before mainnet.**
- Outcall replication → idempotency keys mandatory to avoid N duplicate posts.
- Confirm X API tier permits app-only posting from server-side calls.
