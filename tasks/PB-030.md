# PB-030 — NNS Governance interface bindings

Establish the typed interface to the NNS Governance canister (`rrkah-fqaaa-aaaaa-aaaaq-cai`).

## Scope
- Use the `canhelp` skill to fetch Governance candid; generate Rust types for the methods we need: `list_proposals`/`get_proposal_info`, `get_full_neuron`/`list_neurons`, `manage_neuron` (RegisterVote).
- Define minimal local structs (only fields we consume) to keep payloads small.
- Decide read path: direct inter-canister query vs. off-chain `ic-dashboard` REST for listings (see [[PB-031]]).

## Acceptance criteria
- A test call retrieves a known proposal's info and a neuron's followees.
- Candid types compile and round-trip.

## Notes / pitfalls
- 2MB inter-canister payload cap — page/limit proposal queries.
- Governance interface is large; bind only what's used.
