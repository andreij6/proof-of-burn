# PB-142 — Pool sidebar (collapsible desktop / full-screen mobile)

Add the right-hand pool sidebar. Plan §7 ("Pool sidebar").

## Frontend
- **Desktop:** right-hand sidebar, collapsible to a thin rail via a chevron;
  remember collapsed state (localStorage). Main content reflows to remaining
  width.
- **Mobile:** sidebar hidden behind a toggle ("Pool" button / FAB); opening it
  expands to **full screen** as an overlay with a close button.
- **Top item is always the "Follow" button** (primary CTA) that launches the
  setup wizard (PB-143).
- Below it, the caller's **own entry first** (from `get_my_pool_neuron`):
  - Draft → "Draft" badge + "Resume setup" (re-opens wizard at the pay step).
  - Active → "You" badge + VP + "Leave pool" (`unregister_leader_neuron`).
  - Inactive → muted + "Re-verify"/"Finalize".
- Then other **Active** pool neurons (id, VP); top-25 highlighted as
  payout-eligible. Note that payouts land in the app wallet (withdraw via Wallet).

## Acceptance Criteria
- [ ] Desktop sidebar collapses/expands and the choice persists across reloads.
- [ ] On a narrow viewport the sidebar opens full-screen with a working close
      control; main content is not visually clipped behind it.
- [ ] The "Follow" button is always the top item and opens the wizard.
- [ ] The caller's own entry renders first with the correct action per status;
      other Active neurons list below sorted by VP with top-25 highlighted.
- [ ] `npx tsc --noEmit --skipLibCheck` clean; no console errors when the pool is
      empty.
