# PB-123 — Balance-of-power bar (Yes/No split) + tie-break

Show a balance-of-power bar above the committed-ICP heat bar on each proposal,
splitting committed weight into ADOPT (yes) vs REJECT (no), proportional to ICP
committed. e.g. two 1-ICP commits on opposite sides → 50/50.

## Backend
- Track the **first stance** committed per proposal (`first_stance: opt Stance`,
  serde default) — set on the first commit to that proposal.
- `process_proposal_cutoff`: vote = Yes if adopt_pot > reject_pot, No if reject >
  adopt, and on an **exact tie** use the first stance committed (first vote wins).

## Frontend
- Render a two-segment bar (adopt_pot_e8s vs reject_pot_e8s) above the HeatBar on
  Open + Committed cards, with % labels. Empty pots → neutral/empty bar.

## Tests
- Unit: tie-break selects first stance; majority math both directions.
- Frontend: split proportions (50/50, lopsided, all-yes, all-no, empty).
