# PB-080 — Security review pass (canister-security checklist)

Full review against the IC security checklist before any mainnet burn. **Gates M3/mainnet.**

## Scope
- Verify: anonymous rejection everywhere; admin guards + revocation; CallerGuard on token paths; saga correctness; bounded-wait on all inter-canister calls; no secrets in state; no `pre_upgrade` trap risk; `fetchRootKey()` only in local.
- Consider a dedicated subagent / external review for the burn paths.

## Acceptance criteria
- Checklist signed off; findings filed and resolved or risk-accepted.

## Notes / pitfalls
- `inspect_message` is not a security boundary; every update re-checks access.
