# PB-072 — Proposal card (all tier states)

The core repeating unit; must render locked, unlocked, and active states.

## Scope
- Title + ID, category tag, deadline countdown, status badge (open / threshold met / voted / expired).
- Threshold progress (committed vs required) — richer at Tier 1+.
- Slot for burn input ([[PB-074]]), gated by tier.

## Design source
Recreate `ProposalRow` (`design-system/project/pob-parts.jsx`) + `HeatBar` (`pob-kit.jsx`): category `Chip` + mono ID, title, `clock` deadline `Chip`, status `Chip` (`muted` Open with `LiveDot` / `ok` Threshold met). For anon (Tier 0) the burn progress is wrapped in `Gate` ("Sign in to unlock"); the card border turns `--sprout` when met. Bind to real NNS proposals ([[PB-031]]) — the prototype's `FEED` / `ROAD-…` rows are placeholder.

## Acceptance criteria
- Same card renders correctly across Tier 0→3 with locked/blur overlays where gated.
- Deadline countdown and status badge update live.

## Notes / pitfalls
- Design locked features as visibly gated (tooltips on what unlocks them) per brief.
