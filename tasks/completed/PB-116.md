# PB-116 — Frontend: global stats strip between header and neuron block

Add a strip below the app header (line ~778) and above the neuron block
(line ~843) showing three app-wide metrics:

1. **TVL** — current ICP locked in active proposals (open + met).
2. **Total burned** — cumulative ICP burned via this app.
3. **Proposals voted on** — count of distinct NNS proposals this app has cast a vote on.

## Scope

- Add a `getGlobalStats` call alongside the other data fetches in `refreshAllData`.
  - Use the generated `actor.get_global_stats()`.
  - Store the result in a `useState<GlobalStats | null>`.
- Render a 3-column strip matching the visual style of the existing Tier 3
  strip (border `var(--burn)`, background `var(--burn-950)`, mono numbers
  in `var(--fg)`, eyebrow labels in `var(--fg-3)`), but without the
  `tier >= 3` gate — this is public information.
- Place the new strip **above** the Tier 3 user-strip and **above** the
  tagline + neuron block. Per the request, the placement is "below the
  header and above the neuron."
- Show loading placeholder (`...`) while the data is null.
- Use the existing `Icon` component with `coins` (TVL), `flame` (burned),
  and `checkCircle` (proposals voted on) for visual continuity.
- Eyebrow text: `Locked in escrow`, `Burned to date`, `Votes cast`.

## Acceptance criteria

- The strip renders for **all users** (including anonymous / tier 0).
- Numbers use `fmtICP` so values are human-readable.
- The strip does not interfere with the existing Tier 3 strip below it.
- No layout shift on load: reserve a fixed height while the data is null.
- The frontend `npm test` suite still passes.
- A simple smoke test verifies the strip is present in the rendered output
  (existing tests in `test/`).

## Notes / pitfalls

- The data can be derived from `proposals` + `voteHistory` client-side as a
  fallback, but prefer the dedicated `get_global_stats` query for accuracy
  (one source of truth, see PB-115).
- The current Tier 3 strip is per-user — keep it distinct from the new
  global strip so users can compare their contribution to the app total.
- The eyebrow text in the existing Tier 3 strip uses `Eyrow` (sic — appears
  to be a typo of `Eyebrow`). Reuse the same pattern for consistency;
  don't introduce a new component.
