# PB-003 — Local ICP/ICRC ledger + funded dev identities

Stand up a local ICP-equivalent ICRC-1/2 ledger so burn and commitment flows can be exercised end-to-end before mainnet.

## Scope
- Add a prebuilt `ic-icrc1-ledger.wasm.gz` ledger canister (pin a release tag from dfinity/ic releases).
- Init args: **separate** `minting_account` principal from `initial_balances` principals; `feature_flags = opt record { icrc2 = true }`.
- Create named dev identities (`icp identity new`) and fund several via `initial_balances` (paste literal principals — shell substitution does not expand in init-arg files).

## Acceptance criteria
- `icp canister call <ledger> icrc1_balance_of` returns funded balances for dev principals.
- `icrc2_approve` succeeds from a funded (non-minting) principal.

## Notes / pitfalls
- Minting account cannot call `icrc2_approve`.
- Transfers **to** the minting account are burns and require `fee = 0` (BadFee otherwise). This is the burn primitive used in [[PB-042]].
- On mainnet the real ICP ledger is `ryjl3-tyaaa-aaaaa-aaaba-cai`.
