# PB-136 — `cancel_pool_draft` + `unregister_leader_neuron`

Leave/cancel paths for pool membership. Plan §2.

## Backend
- `cancel_pool_draft(neuron_id) -> Result` (update): caller must be
  `registered_by` with status `Draft`. Delete the entry (frees the neuron for
  re-registration). Funds, if any, are reclaimed separately via
  `refund_registration` (PB-133). `recompute_pool_info()` (no-op for a Draft).
- `unregister_leader_neuron(neuron_id) -> Result` (update): caller must be
  `registered_by` with status `Active`. Set status `Inactive` (kept for history).
  Initiation fee is **non-refundable**. `recompute_pool_info()`. Audit-log
  `pool_leave`.

## Acceptance Criteria
- [ ] `cancel_pool_draft` removes a caller's Draft and frees the neuron_id so a
      different principal can later draft it.
- [ ] `cancel_pool_draft` rejects non-owners and non-Draft statuses.
- [ ] `unregister_leader_neuron` flips Active → Inactive, drops the neuron from
      the VP sum and future payouts, and does not refund the fee.
- [ ] `unregister_leader_neuron` rejects non-owners and non-Active statuses.
- [ ] Unit/integration tests cover owner/non-owner and status guards.
