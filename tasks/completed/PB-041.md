# PB-041 — Threshold tracking & progress

Track total committed vs. required threshold per proposal and expose live progress.

## Scope
- Maintain `total_committed_e8s` per proposal; `threshold_e8s` from config (flat v1 — [[PB-012]]).
- `get_threshold_progress(proposal_id) -> { committed, required, met: bool }` query.
- Emit a "threshold met" domain event for [[PB-042]].

## Acceptance criteria
- Progress bar in the SPA updates as commitments arrive.
- Crossing the threshold flips `met` and triggers downstream burn.

## Notes / pitfalls
- Threshold v1 is admin-set flat; dynamic/governance models deferred (spec open question).
