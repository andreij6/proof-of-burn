# PB-118 — Mobile header: title and sign-in button collide

On phone widths the header (`Proof of Burn - Alpha` + Theme toggle + Sign in /
wallet pill) overflowed and overlapped.

## Fix
- Header padding/title size made responsive via `.app-header` / `.app-header-title`
  CSS with a 640px breakpoint (`index.css`).
- `.hide-mobile` hides the Theme toggle, the "- Alpha" suffix, and the ICP-balance
  parenthetical on small screens.
- Title truncates with ellipsis; action cluster is `flex-shrink: 0`.

## Result
Header fits comfortably on phones; no collision.
