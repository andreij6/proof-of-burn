# PB-023 — Eligibility tier resolution endpoint

Single source of truth for the four progressive-disclosure tiers used by the SPA.

## Scope
- `get_eligibility(caller) -> { tier: 0|1|2|3, authenticated, following, has_committed, holdings_e8s }`.
- Tier 0 anon, Tier 1 authenticated, Tier 2 verified follower ([[PB-022]]), Tier 3 has ≥1 commitment ([[PB-040]]).

## Acceptance criteria
- Endpoint returns correct tier for each of the four states.
- Frontend tier engine ([[PB-073]]) consumes this verbatim.

## Notes / pitfalls
- Keep it a cheap query where possible; expensive follow checks happen in [[PB-022]] and are cached.
