# PB-126 — Treasury Wallet (admin-only withdraw)

Admins can withdraw accumulated treasury ICP (the 50% from PB-125 + protocol fees).

## Backend
- `admin_withdraw_treasury(to: principal, amount_e8s)` — admin-guarded; transfers
  from the treasury subaccount to `to` via icrc1_transfer. Balance-checked.

## Frontend
- "Treasury Wallet" button visible only to admins → modal showing the treasury
  balance (get_treasury_balance) and a withdraw form (destination principal +
  amount) calling admin_withdraw_treasury.
