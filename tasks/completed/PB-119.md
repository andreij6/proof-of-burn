# PB-119 — Frontend could not reach the backend on mainnet

After the mainnet deploy the Open tab was empty, the neuron section didn't load,
and the wallet showed a fake 1000 ICP. The **backend was fine** (20 live NNS
proposals, real voting power) — the **frontend** couldn't call it.

## Root causes
1. `host = window.location.origin` — on mainnet the agent must talk to the IC API
   boundary (`https://icp-api.io`), not the dapp's own canister origin, or every
   canister call fails.
2. `backendCanisterId` fallback on mainnet was `""` (empty) — if the injected
   canister env was missing, the actor was built with an empty id → all calls fail.
3. The ledger balance `.catch` set a **fake 1000 ICP** ("simulated balance"),
   masking the failure and misleading the user.

## Fix
- `host = isLocal ? origin : "https://icp-api.io"`.
- Hardcode mainnet fallbacks: backend `k7dn6-qiaaa-aaaap-qutha-cai`, ledger
  `ryjl3-tyaaa-aaaaa-aaaba-cai`.
- Balance `.catch` now sets `0n` (never fakes a balance).

## Result
Proposals, config (neuron + admin check), leader voting power, and the real ICP
balance all load on mainnet.
