# PB-071 — Neuron identity block

Persistent hero/header element anchoring the follow CTA (entry point).

## Scope
- Primary neuron ID with one-click **Copy**; follow-status indicator (not following / following — verified on-chain via [[PB-022]]); link out to NNS.

## Design source
Recreate `NeuronBlock` (`design-system/project/pob-parts.jsx`): `Eyebrow` "Follow this neuron", mono neuron ID + `copy`-icon button, follow-status `Chip` (`ok` "Following" / `muted` "Not following"), the VP/dissolve meta line, and the "Open in NNS" `external` link. Tier 0 → "Sign in to follow"; Tier 1 not-following → primary "Follow neuron" `Btn`; verified → `sprout` "Verified on-chain". Primitives from `pob-kit.jsx`.

## Acceptance criteria
- Copy works; status reflects on-chain follow state for the signed-in user; NNS link opens the neuron.

## Notes / pitfalls
- Tier 0 shows neuron ID + follow prompt even when anonymous.
