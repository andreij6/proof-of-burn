# PB-100 — Mainnet deployment runbook

Repeatable deploy to mainnet.

## Scope
- Switch to a funded named identity (never anonymous on mainnet); verify ICP/cycles balances.
- `icp deploy -e production` (backend + frontend); confirm `.icp/data/` mappings committed.
- Post-deploy smoke: eligibility, proposals listing, a small-amount commit, history.

## Acceptance criteria
- Both canisters live on mainnet; smoke checks pass; runbook documented.

## Notes / pitfalls
- Anonymous identity on mainnet = uncontrolled canisters / public funds.
- Use `-e ic`/environment, not `--network ic`.
