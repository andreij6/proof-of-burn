# Cycles of Influence — knowledge bundle

An [Open Knowledge Format (OKF) v0.1](https://github.com/GoogleCloudPlatform/knowledge-catalog/blob/main/okf/SPEC.md)
bundle holding this project's knowledge: what the dapp is, how it is operated,
and every feature exploration. Migrated from the former `docs/` and `ideas/`
folders on 2026-07-04 (see [log](/log.md)).

Every concept is a markdown file with YAML frontmatter (`type` is mandatory);
links are bundle-relative. Types in use: `overview`, `runbook`, `playbook`,
`design`, `review`, `note`, `idea`.
