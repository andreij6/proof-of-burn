# Perm Tier (formerly "Early Adopters") — Independent Validation Skill (for AI agents)

You are auditing the **Perm tier** of Cycle Burn (an ICP dapp) — a permanent
staking tier that was previously branded "Early Adopters" and is still named
`early_adopter_*` / `EarlyAdopter*` in the canister code. Money is locked
PERMANENTLY in this tier, so trust must be earned by verification, not
promised. Your job: pull the source, map every advertised rule to the exact
code that implements it, run the test suite, and report whether the
implementation matches the advertisement. Do not take this document's word for
anything — it only tells you where to look.

## 0. Get the code

```
git clone https://github.com/icp-dapp-factory/proof-of-burn   # or the repo URL you were given
cd proof-of-burn
```

All tier logic lives in ONE file: `src/backend/src/lib.rs`, section
"18. Early Adopters". The candid interface is `src/backend/backend.did`. The UI
making the claims is the **"Perm" tier** rendered in
`src/frontend/src/Staking.tsx` (there is no longer a standalone
`EarlyAdopters.tsx`). Daily-ticket accrual lives in `user_daily_tickets`.

## The current model (what the UI advertises)

The Perm tier is a permanent stake into a platform-controlled 2-year neuron.
It rewards stakers with **lottery tickets only — never ICP yield**:
* Stakes are **permanent** — there is no unstake.
* Each whole ICP staked earns a flat **100 lottery tickets per day**.
* The neuron's harvested yield is split **50% treasury / 50% lottery prize
  pot** and is **never** distributed to stakers.
* The tier is **open to everyone, forever** — no membership quota and no
  membership-close threshold.

## 1. The advertised rules → where each one must be enforced

Verify EACH rule by reading the named function. Quote the code in your
report. If a rule is not enforced where stated, flag it loudly.

R1. **Stakes are permanent — no unstake exists.**
    - `grep -n "unstake" src/backend/src/lib.rs` — every hit must belong to
      the separate lossless-staking feature (`unstake(amount, tier)` on
      STAKES/tier pools), NONE may touch `EARLY_ADOPTERS`, `EarlyAdopter`, or the
      early adopter subaccounts.
    - `grep -n "early_adopter" src/backend/backend.did` — confirm the public
      interface has stake/info/rounds methods only; no withdraw.

R2. **Stake goes into a 2-year neuron that follows the primary voting
    neuron (so it votes on NNS proposals).**
    - `advance_early_adopter_bootstrap()`: claim via `gov_claim_or_refresh`,
      then `gov_increase_dissolve_delay(neuron_id, EARLY_ADOPTER_DISSOLVE_SECS)`
      (must equal 63_115_200 s = 2 years), then
      `gov_follow_all_topics(neuron_id, config.primary_neuron_id)`.
    - `gov_follow_all_topics` must cover the catch-all topic AND the
      governance + SNS topics it excludes.

R3. **Reward is lottery tickets only — 100 tickets/day per whole ICP staked.**
    - `user_daily_tickets`: after the lossless-staking tiers are folded in,
      the caller's Perm stake adds
      `BOOSTER_TICKETS_PER_ICP_PER_DAY (= 100) × whole_icp(staked_e8s)`.
    - Confirm `BOOSTER_TICKETS_PER_ICP_PER_DAY == 100` and that the math uses
      whole ICP (sub-1-ICP stakes do not silently earn 0; check the `.max(1)`
      or equivalent flooring).

R4. **Yield is NEVER paid to stakers — it splits 50% treasury / 50% lottery.**
    - `early_adopter_route_yield(yield, fee)`: must return `restake = 0`,
      `treasury = yield / 2`, `lottery = yield / 2 − fee`. There must be NO
      branch that allocates a per-user claimable share.
    - `early_adopter_run_settlement`: the treasury half transfers to the
      treasury subaccount, the other half transfers to the LOTTERY subaccount;
      `distributed_e8s` for the round must be 0.
    - `claim_early_adopter_yield` must hard-refuse — it returns
      `Err("BOOSTERS_NO_YIELD")`. Confirm there is no path that pays ICP to a
      staker. (Any legacy `claimable_e8s` field is retained for upgrade-safety
      and must only ever be drained to the treasury, never paid to users.)

R5. **Open forever — no membership cap, no membership-close.**
    - `early_adopter_stake`: confirm there is NO `membership_closed` /
      `MAX_EARLY_ADOPTERS` gate that rejects new stakers. Anyone may stake at
      any time, including after large yield months.

R6. **Settlement is journaled and idempotent.**
    - `early_adopter_run_settlement` drives an `EarlyAdopterJob` with per-leg
      done-flags so a retried settlement re-uses recorded block indices and
      never double-routes. Verify transfer-before-mark ordering (a failed
      transfer must leave the leg un-marked for retry).
